公開文書には、利用者が指定・操作・拡張するための仕様を記載します。組み込みの配置や見た目は既定動作であり、作図上の正解を定めるものではありません。別の配置・表現は layout / theme の拡張で実現できます。

設計理由、配置候補の評価方法、試行錯誤、監査・進捗記録は公開仕様と分離し、ローカルの内部メモとして管理します。公開文書から内部メモへはリンクしません。
