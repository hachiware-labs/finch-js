# 継承ソース・線色・文字修飾

## 継承ソース
状態機械の継承を解決した source に、破線、接続ポート、遷移種別、icon/image/imageShape/wrapWidth、任意の追加属性を保持します。内部の描画用データは直接書き出さず、状態動作などの宣言から再構成します。

## 線色
共通属性で指定できます。

```text
A -> B [lineColor=red]
```

クラス図は通常の関係記法（例: A --> B）に属性を付けます。
component/deployment/usecase では PlantUML 形式も使えます。

```text
A -[#336699,dotted,thickness=3]-> B
```

線と矢印・菱形を同じ色にします。色名または16進色を指定します。個別色はテーマ切替後も保持します。未指定はテーマ色です。複数色の線やグラデーションは今回の対象に含めていません。

## 文字修飾
ラベル・注釈に次の書式を使えます。

| 修飾 | 書式 |
|---|---|
| 太字 | `**文字**` または `<b>文字</b>` |
| 斜体 | `//文字//` または `<i>文字</i>` |
| 取り消し線 | `--文字--` または `<s>文字</s>` |
| 部分色 | `<color:red>文字</color>` |
| リンク | `[[https://example.com ガイド]]` |

HTML形式の太字・斜体などは入れ子にできます。折り返した行にも修飾を引き継ぎます。リンクはHTTP/HTTPSを対象とし、SVGにリンクとして保存します。PNGは画像なのでリンク操作はできません。
任意のHTMLを埋め込む機能ではありません。未対応タグは通常の文字として扱います。文字幅はブラウザ測定と余裕を持たせた折り返しを使用します。
